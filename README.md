# Mobilidade WOD

App de alongamento e mobilidade com timer, feito para quem treina CrossFit e musculação.

- Monta a rotina pelo **treino do dia** (agachamento, levantamento terra, olímpicos, puxadas etc.) ou pelo **grupo muscular**.
- **Antes do treino:** movimentos dinâmicos. **Depois do treino:** alongamentos parados.
- 42 exercícios com fotos reais animadas, instruções e o estímulo esperado.
- Timer por exercício, troca de lado automática, bipes e voz em português.

## Como usar

Abra o `index.html` no navegador. Não precisa instalar nada.

Para publicar na internet com o GitHub Pages: em **Settings → Pages**, escolha o branch `main` e a pasta `/ (root)`. No iPhone, abra o endereço no Safari e use **Compartilhar → Adicionar à Tela de Início**.
